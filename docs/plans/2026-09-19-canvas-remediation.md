## D1 · 低难度（先把画布变成能推进工作的视图）

### R1 始终画出空槽节点

**问题重点**  
`dramaCanvasAdapter.js` 的 `appendMediaImageNode` 在 `if (!url) return fromId` 时直接跳过；视频 / 音频同样「没 URL 就不建节点」。制作中的项目在画布上像已经完成的资产墙，缺什么看不见。

**怎么改**

1. `appendMediaImageNode` 允许 `url` 为空，仍创建节点，`data.empty = true`。
2. `buildEpisodePipeline` 按模式**固定**媒体链，不要因为缺资源而缩短：
   - 经典：`sbtxt → sbimg → sbvid`（有对白再加 `sbaud`；无对白也要画音频空槽，标记 `empty` + `skippedReason`）
   - 首尾帧：`sbtxt → sbimg-first → sbimg-last → sbvid`
   - 全能：`sbuni`（无词也占位）→ `sbvid`
3. `CanvasMediaNode` / `CanvasMediaPanel`：空槽显示虚线框 + 「待生图 / 待生视频 / 待配音」+ 主按钮。
4. 空槽节点 ID 必须与有媒体时相同（`sbimg:{id}` / `sbimg-first:{id}` 等），避免生成后坐标跳动。

**不改什么**  
不改列表模式；不在本条做首尾帧专用生图（那是 R8）；全能模式仍然不出现经典分镜图空槽。

**核验**

- [ ] 单测：给无图无视频的 drama fixture 调 `buildDramaCanvasGraph`，经典模式每个分镜都有 `sbtxt` / `sbimg` / `sbvid`；首尾帧模式有 `sbimg-first` 与 `sbimg-last`，即使 URL 为空。
- [ ] 手工：打开缺图项目，画布上行内能看到空的「分镜图」「视频」卡片，不是断链。
- [ ] 对该空槽点「生图」，成功后同一节点出现缩略图，坐标不变（仍读 `canvas_layout.nodes[sbimg:{id}]`）。
- [ ] `npm run build` 通过。

### R2 压缩顶栏 chrome，把屏幕还给画布

**问题重点**  
`DramaCanvas.vue` 实际是三层顶栏（`AppHeader` + `.workflow-bar` + `.generate-bar`）+ 220px 侧栏 + 左下浮动条 + 右下小地图。画布可视区域被表单页布局吃掉。

**怎么改**

1. 工作流条与本集生成条默认收进 Header 的「更多」抽屉或一条可折叠的次级工具条，默认折叠，只留：集数筛选、布局状态、对齐、列表模式、一个「生成 / 工作流」按钮。
2. 左下「快速新建」与顶栏新建、右键新建三选二：保留右键 + 顶栏，去掉浮动条，或把浮动条收成一个 `+`。
3. 侧栏改为可折叠（宽 220 ↔ 0/48），折叠后素材高亮仍可用（点节点本身）。
4. 小地图默认缩小，hover / 点击放大；不要永久占右下大块。

**不改什么**  
不删任何生成 / 工作流能力；按钮可以搬家，不能消失。`AppHeader` 的公共结构保持。

**核验**

- [ ] 默认进入画布，工具条总高度（Header + 次级条）明显小于现在三层全展开；画布区域高度增加可目测。
- [ ] 折叠后仍能：选工作流并整组重跑、AI 生成分镜、批量生图/生视频、新建分镜/角色/场景/道具/集。
- [ ] 侧栏折叠后，单击角色节点仍能高亮关联分镜。
- [ ] 明暗主题下 Header / 抽屉不错位。现有 `tools/ui-verify` 里 DramaCanvas 条目（workflow-bar / generate-bar / 新建 / 对齐 / 列表模式）按新 DOM 更新选择器后全绿。
- [ ] `npm run build` 通过。

### R3 节点详情改为右侧 Inspector，禁止再挂在节点下面

**问题重点**  
分镜 / 媒体 / 素材 / 剧本面板现在 `v-if="showPanel"` 直接挂在节点下方。行距 `SB_GAP_Y = 280`，一展开就盖住下一镜，也无法在看图的同时改下一镜字段。

**怎么改**

1. 四个 `Canvas*Panel.vue` 从节点内部拆出，改为 `DramaCanvas.vue` 右侧固定 Inspector（建议宽 320～360，可关闭）。
2. `focusedNodeId` 仍决定打开哪个面板；单击空白关闭。
3. 面板继续 `nodrag nopan`；`nowheel` 只加在 textarea / 音视频控件上（保持缩放修复）。
4. 节点本身只保留状态条、缩略图、空槽 CTA 的短按钮（可选，点了仍打开 Inspector）。

**不改什么**  
不改面板里的字段与 API 调用；不把 Inspector 做成新路由。

**核验**

- [ ] 单击分镜，右侧出现面板，节点下方不再长出一块；下一镜完全可见、可点。
- [ ] 单击分镜图 / 视频 / 角色 / 剧本节点，Inspector 内容切换正确。
- [ ] 在 Inspector 里保存字段、生图、生视频、配音、删除分镜，行为与现在一致。
- [ ] 打开 Inspector 后滚轮仍缩放画布（光标在画布上）；光标在 textarea 上滚动不缩放。
- [ ] 窄屏（宽度 &lt; 1280）Inspector 可覆盖画布但不挡住缩放控件。
- [ ] `npm run build` 通过。

### R4 分离右键平移与右键菜单

**问题重点**  
`:pan-on-drag="[1, 2]"` 让右键拖拽平移，同时 `@pane-context-menu` 又弹出「在此添加」。短按 / 拖拽容易打架。

**怎么改**

1. 右键按下移动超过阈值（建议 4px）→ 只平移，不弹菜单。
2. 右键按下并松开且未移动 → 弹菜单。
3. 中键始终平移；左键空白拖拽仍是框选。
4. 菜单打开时再按右键拖拽，先关菜单再平移。

**不改什么**  
不改左键框选、滚轮缩放、中键平移。

**核验**

- [ ] 空白处右键点一下：菜单出现，选「分镜」能在该坐标创建。
- [ ] 空白处右键按住拖：画布平移，不出现菜单。
- [ ] 中键拖：只平移。
- [ ] 左键拖空白：框选分镜，顶栏「已选 N 个分镜」更新。
- [ ] `npm run build` 通过。

### R5 空槽可点生成 + 视频可悬停预览

**问题重点**  
空槽即使画出来（R1），若不能就地点生成，画布仍是回顾器。视频节点目前 `muted` 静帧，无法快速看连续性。

**怎么改**

1. 空图槽按钮调用现有 `runImageStep`；空视频槽调用 `runVideoStep`；空音频槽调用 `runAudioStep`。忙碌态走 `nodeStatus`。
2. 有 URL 的视频节点：鼠标悬停静音循环预览；移出暂停并回到第一帧。Inspector 里保留带控件的 `<video>`。
3. 图片节点 hover 可放大到约 360px 预览（portal 到 body），不改变节点尺寸。

**不改什么**  
本条不接首尾帧专用 `frame-prompt`（R8）；悬停预览不做音轨。

**核验**

- [ ] 空「分镜图」点生成，节点进入「生图中」，完成后出图。
- [ ] 空「视频」在缺图时点生成，给出与现在一致的明确错误（缺少分镜图），不静默失败。
- [ ] 有视频的节点悬停自动播放（静音），移出停止。
- [ ] 图片 hover 放大预览，不把整行撑开。
- [ ] `npm run build` 通过。

### R6 补齐画布快捷键

**问题重点**  
目前除 Vue Flow 默认外没有快捷键表，缩放 / 适应 / 取消选择全靠鼠标。

**怎么改**（在 `DramaCanvas.vue` 或独立 composable 监听，输入框聚焦时不触发）

| 键 | 行为 |
|---|---|
| `Esc` | 关闭 Inspector、关闭右键菜单、清除框选 |
| `F` 或 `1` | `fitView` |
| `0` | 缩放到 100% |
| `+` / `=` / `-` | 放大 / 缩小 |
| `Delete` / `Backspace` | 删除当前焦点分镜（需确认框，与面板删除同一 API） |
| `Space` 按住 | 临时变成拖动画布（松开恢复框选） |
| `Ctrl/Cmd + S` | 立即 `persistCanvasState` |

屏幕角落放一个 `?` 打开快捷键说明。

**核验**

- [ ] 焦点在 textarea 时按 `Delete` / `F` 不误触发。
- [ ] 空白画布按 `F` 适应；按 `0` 到 100%（与右上角控件一致）。
- [ ] `Esc` 关掉 Inspector 与菜单。
- [ ] Space 按住左键拖 = 平移；松开后左键拖 = 框选。
- [ ] `npm run build` 通过。

### R7 节点级忙碌 / 失败徽章，替代「一行字进度」

**问题重点**  
整组重跑只有 `.workflow-progress` 一行。失败停在哪一镜、哪一步，要读 toast。

**怎么改**

1. 扩展 `useCanvasNodeStatus`：支持 `status: 'busy' | 'error' | 'ok'`，error 带 `message`。
2. `runWorkflowGroup` 的 `onStepStart` / `onStepError` / `onStoryboardComplete` 写入对应 `sb:` / `sbimg:` / `sbvid:`。
3. 节点卡片显示小徽章：生成中脉冲、失败红点、完成可在 2s 后消失。
4. 顶栏进度改为 `3/10 镜 · 生视频`，失败镜号可点击定位（`setCenter` / `fitView` 到该节点）。

**不改什么**  
本条不改「失败即停」策略（R10 才改）；不改后端。

**核验**

- [ ] 跑工作流时，当前镜的图/视频节点有忙碌态，其他镜没有假忙碌。
- [ ] 人为让第 3 镜缺提示词导致失败：第 3 镜红点，顶栏可点跳到该镜，toast 仍在。
- [ ] 刷新页面后红点可以不保留（本条不要求持久化失败态）。
- [ ] `npm run build` 通过。

### R8 画布内首尾帧单独生图

**问题重点**  
列表模式有 `generateFramePrompt` / `saveFramePrompt` / 一键生成首尾帧；画布只能当普通 `runImageStep`，首尾帧模式空槽无法按槽位生成。

4. 生成后 `loadForDrama` + `rebuildGraph`，空槽变实图。

**不改什么**

### R10 工作流：跳过已完成、失败后续跑、单镜重试

**问题重点**  
`runWorkflowGroup` 全量顺序执行，`stopOnError: true`。重跑会把已成功的镜再打一遍钱；失败后不能从失败镜继续。

**怎么改**（仍可先留在前端）

1. 创建/执行工作流时增加选项（默认开启「跳过已有」）：
   - 跳过已有图 / 已有视频 / 已有配音（用 `hasStoryboardImage` / `hasStoryboardVideo` / 对白音频路径判断）。
   - 失败后：停止 | 记录失败并继续后续镜。
2. 执行摘要：`ok` / `skipped` / `failed`；顶栏与 Inspector 可「只重跑失败」。
3. 单镜：Inspector 增加「重试本步」，不跑整组。
4. 纯函数抽出 `planWorkflowSteps(sb, pipeline, flags)` 并写单测。

**不改什么**  
本条仍是前端编排；关浏览器仍会停（R15 才做后端队列）。不改计费。

**核验**

- [ ] 单测：已有图无视频、pipeline=`[image,video]` → 计划为 skip image + run video。
- [ ] 10 镜中 8 镜已有图和视频，勾选跳过：只对缺的 2 镜发请求（网络面板 / 日志可证）。
- [ ] 第 3 镜失败且选择「继续」：第 4 镜仍执行；结束后失败列表含第 3。
- [ ] 「只重跑失败」只请求失败镜。
- [ ] `npm run build` 通过。

### R12 工作流组可视化（分组框，不是自由接线）

**问题重点**  
`workflow_groups` 只在分镜小黄标和侧栏列表出现，画布上看不出「这一场」。第五节 5.1 的可兑现部分是「看见组」，不是「手拉 DAG」。

**怎么改**

1. 为每个 group 画一个不可连接的背景框节点（或 Vue Flow parent node），包住组内分镜卡片（不含媒体链也可，先包 `sb:*`）。
2. 框上显示标题、镜数、pipeline、运行按钮。
3. 组内分镜顺序：框内列表可拖拽排序，写回 `storyboard_ids` 并 `persistCanvasState({ groupsOnly: true })`。
4. 仍禁止用户手拉 `sbimg → sbvid` 以外的边；`:nodes-connectable="false"` 保持。

**核验**

- [ ] 创建工作流后，组内分镜被同一色框包住；侧栏点组名，框高亮。

### R14 布局撤销（只撤销坐标与视口）

**问题重点**  
拖乱节点或误点「对齐节点」无法恢复。不需要做成通用编辑撤销。

**怎么改**

1. 对 `canvas_layout` 做最多 30 步内存栈；`node-drag-stop`、对齐成功、`fitView` 写入前 push。
2. `Ctrl+Z` / `Ctrl+Shift+Z` 恢复节点坐标与 viewport，并 debounce 保存。
3. 对齐前把当前 layout push 进栈，核验才能成立。

**不改什么**  
不撤销「生图 / 删分镜 / 改剧本」。那些继续用各自确认框。

**核验**

- [ ] 拖动一个节点，Ctrl+Z 回到原位，刷新后仍是原位（已保存）。
- [ ] 对齐节点后 Ctrl+Z 回到对齐前的手工布局。
- [ ] 在 textarea 里 Ctrl+Z 走浏览器文本撤销，不挪节点。
- [ ] `npm run build` 通过。

## D3 · 中高难度（执行模型与规模）

前置：R10 完成后再做 R15/R16。

### R15 工作流组改为后端任务，关页不断

**问题重点**  
`runWorkflowGroup` 跑在浏览器 tab 里。关画布、刷新、Electron 切页都会中断，且无法多端看进度。这是相对秒哒 / 即梦 / LibTV 队列的本质差距。

**怎么改**

1. 新后端接口例如 `POST /api/v1/dramas/:id/workflow-runs`，body：`group_id` 或内联 `storyboard_ids` + `pipeline` + R10 的 skip/continue 旗标。
2. 用现有 `taskService`（或等价表）存 run：状态、当前镜、每镜每步结果。
3. 前端只负责创建任务 + 轮询 / 轻量轮询（可复用 `taskAPI.get`）；节点徽章读任务快照。
4. 进入画布时若有 in_progress run，自动接上进度。
5. 「停止」调用取消接口，已发出的上游生图任务按现有 task 取消语义处理（没有取消能力则标记 cancelled、不再发后续镜）。

**不改什么**  
单镜手动点「生图」仍可走现有前端 `runImageStep`（或一并改为同一 task 通道，但不强制本条一次做完）。

**核验**

- [ ] 开始整组重跑后立刻刷新页面：任务继续，节点状态在 ≤3s 内恢复。
- [ ] 关 Electron 窗口再开（后端仍在）：任务仍在跑或已完成，画布能看到结果。
- [ ] 点停止：不再对后续镜创建新的 images/videos 任务。
- [ ] 失败镜信息可从 `GET` run 记录读到，刷新不丢。
- [ ] 后端测试覆盖：skip 已有资源、stopOnError、continue-on-error。
- [ ] `npm run build` 通过。

### R16 独立分镜可并行（有上限）

**问题重点**  
镜与镜之间没有数据依赖时仍串行，四十镜一场戏极慢。R9 的尾帧衔接是例外。

**怎么改**

1. 默认并发 2，可在工作流选项里设 1～4。
2. 若 pipeline 含视频且用户开启「按镜序衔接首帧」，强制并发 = 1。
3. 实现放在 R15 的后端 run loop；不要在浏览器里 `Promise.all` 打爆上游。

**核验**

- [ ] 无衔接、并发 2：同一时刻最多 2 个 in_progress 的图或视频任务。
- [ ] 开启衔接：即使设了 4 也顺序执行。
- [ ] 限流（429）时该 worker 退避，不把整个 run 打挂（可重试 1～2 次再记失败）。
- [ ] 后端测试覆盖并发上限。

### R18 视口节点虚拟化

**问题重点**

**核验**

## D4 · 本轮明确不做

这些是分析第五节里的真实差距，但不是这轮整改的合格线。开工会把画布做成另一种产品。

| 编号 | 内容 | 原因 |
|---|---|---|
| W1 | 用户自由拉线、自定义节点、子图、A/B 分支 DAG | 违反「画布是视图层」；真源是分镜表不是图文档 |
| W2 | 多人光标 / 评论 / 实时协作 | 本地桌面单用户工具，无协同后端 |
| W3 | Krea 式无限画布 inpaint / outpaint / 情绪板 | 赛道不同 |
| W4 | 列表模式 100% 能力搬进画布（四宫格、Seedance2 资产、小说导入、旁白烧录细节、连贯帧整集） | 先把 R8–R19 的主路径做完 |
| W5 | LibTV 导演台、逐帧拉片、动作捕捉、Blender 插件、智能剪辑 | 成片工具链，不是本轮画布视图 |
| W6 | 把「对齐节点」做成完整 Figma 级对齐体系 | R14 已覆盖误操作；吸附/分布收益低 |

若以后要做 W1，必须先写新的真源设计（图即文档），不能在现有 adapter 派生边上硬接。
